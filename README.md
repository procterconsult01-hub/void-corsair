# Space Pirates: Void Corsair

A browser space-shooter with a pirate theme, procedural sound, four boss waves, a Hall of Infamy leaderboard, and a coin and upgrade shop.

## Play

- **Game:** https://procterconsult01-hub.github.io/void-corsair/
- **Privacy policy:** https://procterconsult01-hub.github.io/void-corsair/privacy.html

In a normal browser the shop runs in demo mode. Inside the Android app, purchases go through Google Play.
